# Time Machine Warning

A one-line warning label for a time machine, written for the make.fun bounty "Funniest Time Machine Warning Label". The program writes the label to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The label turns the grandfather paradox into a customer-service joke: a deadpan safety notice whose punchline — the refund policy — only lands in the last three words.

Run it with Node 22:

```sh
node main.ts
```
